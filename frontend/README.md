# AlgoMap - Frontend

Welcome to the frontend repository for **AlgoMap**. This application is built using **React** and **Vite** to ensure a fast and responsive user experience.

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (comes with Node.js) or yarn

### Installation

1.  **Navigate to the frontend directory:**
    ```bash
    cd frontend
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

## 💻 Usage

### Development Server
To start the application in development mode with Hot Module Replacement (HMR):
```bash
npm run dev
```
Open http://localhost:5173 to view it in the browser.

### Production Build
To build the app for production:
```bash
npm run build
```

## 🛠 Technologies

- **React**: UI Library
- **Vite**: Frontend Tooling
- **ESLint**: Code Linting
